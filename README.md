# RentaExpress — Marketplace de Autos

RentaExpress es una aplicación web desarrollada con **Spring Boot** y **Thymeleaf** que permite publicar, buscar y administrar vehículos en renta o venta.  
Su objetivo es ofrecer una plataforma moderna y fácil de usar para conectar propietarios y clientes.

---

## Tecnologías utilizadas

- **Backend:** Spring Boot (Java)
- **Frontend:** Thymeleaf, Bootstrap, HTML5, CSS3, JavaScript
- **Base de datos:** PostgreSQL
- **Servidor de aplicación:** Apache Tomcat (integrado)
- **Control de versiones:** Git & GitHub

---

## Características principales

- Registro e inicio de sesión de usuarios  
- Publicación de autos con imágenes, descripción, precio y disponibilidad  
- Gestión de publicaciones (editar, eliminar, ver detalles)  
- iseño responsive con Bootstrap  
- Conexión a base de datos PostgreSQL
